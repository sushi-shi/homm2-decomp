# Semantic naming implementation: Price of Loyalty

All 80 scoped proposals from [PR #65](https://github.com/sushi-shi/homm2-decomp/pull/65) are applied to declarations, definitions and consumers. The mixed-role `EvaluateMonsterEvent::attackerLoss` remains unchanged, as proposed. Public function names and string/character literal payloads are preserved.

This is an unmerged implementation PR against `decomp-pol`. The README branches receive separate review PRs; no integration branch is changed by this checkpoint.

The rebuilt retail objects preserve all non-debug section layouts and bytes, named symbols and complete ordered relocations: **95 objects, 40090 relocation sites** compare identically before and after. Compiler-counter suffixes are normalized by the existing strict object comparison, without changing storage or relocation identity. Gold retains 1,727/1,727 live exact functions; PoL retains its prior 1,168/1,514 live exact functions. Both retain 100% compared data. Historical maxima remain source-hash scoped and are regenerated by the normal tools.

Retail-only aliases preserve measured local-name frame allocation. The two SEARCH file statics also retain their measured compiler identities under the existing non-strict build switch: changing their spelling alone changed BSS ordering. Modern and generated source expose the semantic road names. No padding or probe declarations are retained.

The implementation verifies every scoped proposal and unchanged literal payloads. PoL's differently named locals are translated by actual call argument positions, including the reversed old TownEvent casualty names. The native maintained branches also build and pass their existing CTest suites (master 23, ironfist 24, ironfist-master 26).

Tool verification passes: 543 tool tests, including the clean generator alias-removal test.
