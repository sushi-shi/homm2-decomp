## B72: event contracts and preserved retail behavior

ValueOfEventAtPosition returns a cached value before initializing the chance
output or the reload/berserk policy globals. The ordinary instruction bytes
and ordered targets at these sites agree with retail:

```text
+0x51  e9 c6 17 00 00   jmp cached_return
+0x56  c7 05 ... 01...  mov [gbReduceByReload], 1
+0x60  c7 05 ... 01...  mov [gbReduceByBerserk], 1
+0x6d  c7 00 64 00...   mov [eax], 100  ; *liveChance
```

The value cache alone cannot restore those outputs. Several event evaluators
also return early without assigning chance and rely on caller initialization.
These contracts are documented without claiming an instrumented gameplay
failure or silently moving initialization across the cache return.

EvaluateMineEvent (`0x8b4c3`) truncates the battle probability directly:


Unlike monster/hero/town evaluators, this sequence has no multiplication by100.
The whole696-byte function passes independent retail byte/site/ordered-target
comparison. For a probability in[0,1), the integer output is0; no percentage
repair is applied to matching retail behavior.
