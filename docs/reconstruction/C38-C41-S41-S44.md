`game::ViewArmy` (`0x55529`) now declares `armyName0` as `char[32]`.
Its two `reinterpret_cast<char*>` uses disappear. The existing case-folding
helper still accepts an unsigned byte and returns a text character. Converting
the input character to that unsigned parameter preserves all256 bit patterns;
Cyrillic comparisons are not performed on a negative signed `char`.

The complete unsigned-owner/text-owner family completed2/2 in4.294s.
Then, under that recovered text-owner parent, the five independent argument
axes (attack, defense, minimum/maximum damage, standalone hit points) completed
all32 combinations in38.173s. Every arm has3336 bytes,182 candidate relocations,
text hash`5d0dde5aae5f6a53`, and105 diagnostic blocks/805 instructions. Neither
matrix was truncated; both restored source. No AST/TU-state probes were mixed
into these products.

The four signed-byte statistics naturally promote to `int`; the u16 hit-point
value also fits `int` and naturally promotes. That matches `%d` without a
written cast. The separate unsigned hit-point subtraction is unchanged: its
arithmetic domain is not established merely by the standalone printf argument.
Coordinate narrowing and literal constness are separate remaining candidates.

At function`+0x3f6`, `8d 55 b0` still takes the actual32-byte name at ebp-0x50.
At`+0x402`, `8b 45 b0`, followed by `25 ff 00 00 00`, retains the unsigned
character value for the inline case fold. At`+0x48c`, `88 55 b0` stores the
resulting byte. Both old/new source forms reproduce those same accesses.

Both matrix strict verdicts remain false. Independent final comparison proves
all3336 ordinary bytes, but leaves four EH operands unresolved (`+6` private
handler, `+c`, `+14`, `+cfd` exception-list references), and the DIR32-site

not by the99.983850% fuzzy score.
