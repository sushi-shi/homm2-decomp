The spell producer review includes `InitClean`, `CancelIndividualSpell`,
`SetSpellInfluence` and `DecrementSpellRounds`: normal initialized nonzero
duration transitions preserve count consistency; arbitrary durations do not.
This is not a claim that malformed counts or an actual normal-game overread
were reproduced. Likewise, no-check text copies are recorded as contracts,
not replaced by truncation that changes the target's behavior.

The static `gCombatMessageText` has a real 400-byte claim. The two 120-byte
manager strings are distinct fields at +0x33a and +0x3b2. The general 400-byte
scratch contract cannot be used to certify those smaller destinations. Default
view/combat/spell help tables separately fit at most22/31/37 bytes including
NUL; that does not prove every formatter/caller input is bounded to119.

There is no enclosing-owner subtraction, manual argument-slot access, artificial
address arithmetic or avoidable newly introduced union. The message and monster
flag views retain their existing owner-ledger semantics; reviewing these
consumers does not silently close earlier union findings. No array is flattened
across a subobject boundary or shrunk merely because a rectangular filler cell
is not selected.
