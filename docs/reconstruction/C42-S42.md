# C42/S42: turn-update flags, casts and unread locals

The clean parent is `4d53d37f`. Both complete bodies and their flag, mana,
player-mask and save-name declarations were reread. Ten cast expressions
are removed across seven statements. Both unused-local candidates remain
after complete native-changing experiments.

## NextPlayer

The two available heroes now clear HERO_EVENT_WEEKLY_VISIT with typed
compound assignments. The actual owner is the existing u32 HeroEventFlag
domain, which already provides typed bitwise operators for the strict
dialect. The retail dialect uses the same unsigned integer storage.
No signed scalar view or enum reconstruction is needed to clear bit 16.
This preserves all other bits, including the high bit. The selected
compound operations also reproduce the retail address evaluations.

The current-player mask now narrows naturally into its existing u8
destination. Valid player IDs 0..5 produce masks 1..32. The autosave literal
is passed directly to the existing const-correct SaveGame interface.
Neither change alters the call ABI or serialized data.

The unread humansAlive calculation is not removed. Its complete deletion,
including the declaration and six-player loop, changes 1290 to 1216 bytes in
every tested arm. The retail frame reserves 0x14 bytes. Keeping the count
is necessary for this measured parent, not evidence that the value has a
later consumer or that no future structural recovery is possible.

Available-hero IDs, hero-list counts/IDs, six-player mappings, terrain/music
indices and terminated player names remain B61 contracts. Player rotation
requires a valid positive player count and a survivor. This change adds no
new guards or gameplay behavior.

## PerDay

The daily hero loop clears the existing WEEKLY_HERO_RESERVED_FLAG alias
with the same typed compound operation. Both mana writes now use their
actual i16 destination conversions. Their i32 arithmetic and comparison
order remain unchanged; this does not impose a new mana clamp or define
overflow. The handicap float-to-i32 cast stays: it truncates the computed
penalty before integer subtraction, which is real semantics.

The unread income8 declaration stays. Deleting it retains 2576 total bytes
and the same graph, but changes the frame reservation from 0x38 to 0x34 and
shifts live stack operands by four bytes. For example, the initial saved
this operand moves from -0x2c to -0x28. Size and graph equality therefore do
not prove byte equivalence. All 12 deletion arms show this distinct byte
sequence; all 12 retained-local arms preserve the baseline sequence.

R09's player/mine/town/hero index reuse remains a separate finding. Mine
owner/resource validity is still required: the existing upper resource
bound alone does not reject negative types. Player counts, 54 hero records,
72 towns, occupying-hero IDs and mana arithmetic require valid game state.
The explicit day guard 1..6 safely selects resource indices 0..5. Earlier
U12/U13 owner and bitset recovery remains unchanged.
