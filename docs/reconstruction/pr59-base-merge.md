## Review-ledger revision boundary

The original audit completed 1,656/1,656 function and 229/229 file readings at
the pre-merge head. That historical result is preserved in Git and the reports.
The current base changes many authored bodies through helper calls and localized
IDs, adds two header helpers and removes four local case-fold helpers.

Regeneration deliberately leaves changed/new bodies pending rather than silently
assigning their old reviews to new hashes: 1,202/1,654 functions retain matching
review hashes; 452 require source-level review refresh. Likewise, 129/229 file
review hashes still match, and the macro census now contains 792 definitions.
Native equivalence is not a substitute for that ten-pattern manual review.

Existing notes and finding dispositions remain intact. The logger's review key
was migrated to its default-argument signature without changing its old hash.
The four removed local-helper reviews are preserved separately in
`pr59-superseded-reviews.json`. The remaining research is intentionally not
extended here: this merge makes the delivered PR reviewable on the current base.
