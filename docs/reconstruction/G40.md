# G40: retain the level-up skill-search goto

`hero::CheckLevel` uses `goto nextAttempt` when the weighted scan selects a
skill. The label follows the while-loop and precedes `tryCount--`. A normal
`break` is behaviorally equivalent here: there is no intervening declaration,
destructor or outer-loop exit. It is not byte-equivalent in this VC6 build.

The complete two-arm source matrix compiled both the unchanged goto and the
break-with-label-removed alternative in 2.52 seconds. There were two distinct
source products and two emitted states; no wall-time truncation or TU-state
probes. Results: `build/g40-batch/results.json`; exact-span manifest:
`build/g40-axes.json`. The source alternatives are preserved in
`docs/matching/hero-CheckLevel/skill-search-exit.cpp`.

| Measurement | Goto control / retail | Break candidate |
| --- | --- | --- |
| Function bytes | 1699 | 1689 |
| Relocations | 56 | 56, later sites shifted |
| Basic blocks | 67, exact graph | 66, different graph |
| Fuzzy diagnostic | 100% | 99.411766% |
| Successful-choice branch at `+0x3e3` | `e9 b2 02 00 00`, jump to `+0x69a` | `eb 1c`, jump directly to `+0x401` |
| Trampoline | `+0x69a: e9 65 fd ff ff`, jump back to `+0x404` | absent |
| Normal tail | `+0x698: eb 05`, skip trampoline | no skip needed |

The three-byte shorter selection jump plus removal of the five-byte trampoline
and two-byte tail skip account for all ten bytes. `tryCount--` moves from
`+0x404` to `+0x401`; it is still executed. This is a lowering change, not a
missing source operation or a stack-buffer recovery. No fake jump, volatile
state or padding has been added to recover the bytes.

Both runner strict exact flags reject private relocation identities, including
the control. The break arm additionally has real size/byte/site differences;
its four sibling private-relocation warnings are not why it is rejected.
After source restoration, the independent genuine-retail checker passes all
1699 bytes, every DIR32 site and every ordered target. All 44 native HERO
functions and all allocated sections/ordered relocations also equal the fresh
pre-matrix snapshot. Full build remains 1727/1727 exact. See
`build/g40-restored-{native,retail}.log` and `build/build-g40-restored.log`.

Disposition: retain this ordinary, fully understood goto. The simple structured
replacement has been measured and rejected; this finite test does not claim
that every possible source family has been exhausted. A new search would need
new structural evidence, not arbitrary spelling or code-size steering.
