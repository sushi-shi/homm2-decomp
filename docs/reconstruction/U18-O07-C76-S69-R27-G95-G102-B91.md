still includes its actual18 opaque bytes; this review does not invent a typed
union over them or delete them as unused padding.

C76 removes71 redundant numeric casts: nine byte assignments,54 widget
arguments, one rating assignment, two signed32-bit clock comparisons, two
cursor arguments, two usual unsigned `strlen` comparisons and one character
assignment. Numeric conversions still occur at the actual destinations.

signed16-bit truncation must remain. Removing that inner conversion changes
2673 bytes to2672. The other actual enum-domain conversions, allocation casts
and transport reinterpretations remain. Written cast count is85→13, not a
claim that all72 removed spellings were redundant conversions.

including cancellation that can lead back to selection, is unchanged. Four
indented VA annotations were left-aligned so the existing permutation parser
could isolate the functions; no tool or annotation address was changed.
