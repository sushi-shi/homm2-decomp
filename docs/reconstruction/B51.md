# B51: KB table domains and the unused mage-level clamp

`GetBuildingCost` (`0x00468beb`) independently passes all 240 function bytes,
DIR32 sites and ordered targets against the pinned genuine executable
(`build/b51-cost-retail.log`). The mage-building path computes and clamps a
local `level`, then ignores it when selecting the cost row:

| Function offset | Retail and current VC6 instruction | Meaning |
| --- | --- | --- |
| `+0x78` | `83 7d fc 05` | Compare local level with 5 |
| `+0x7e` | `c7 45 fc 05 00 00 00` | Clamp local to 5 |
| `+0x85` | `6a 1c` | Copy seven 32-bit resource costs |
| `+0x87` | `8b 45 0c` | Reload original mage-level argument |
| `+0x8a` | `83 c0 01` | Add one again |
| `+0x8d` | `6b c0 1c` | Row stride 28 |
| `+0x90` | `05 …` | Add cost-table owner `0x004fbfc0` |

The table has six rows. This path requires `mageLevel + 1` in `0..5`;
the local clamp is not a bound on its actual access. In particular, a mage-level
argument of 5 selects the one-past row. Unsupported building kinds can return
without filling the caller's seven-cost output. Callers and valid building
progression must establish the input domain; this is not a demonstrated ordinary
gameplay crash. Do not redirect the access to `level` or enlarge the table merely
to make the source look safe: both would misrepresent the measured retail code.

Other KB domain findings remain open in the per-function ledger: menu command
`0x6a` is inside the handler's accepted range but outside its five hotspot rows;
the debug formation command range admits 200 indices into a 25-entry table;
dialog resource kinds and live game/player/hero ownership require caller and
resource contracts. Independent checks additionally pass all 1561 bytes/sites/
targets for `InitMenuHandler` (`0x0046829b`) and all 2256 for
`HandleAppSpecificMenuCommands` (`0x0046d715`), including the actual hotspot and
formation owner operands (`build/kb-clean-0x{6829b,6d715}-retail.log`).
This corroborates the accesses and accepted ranges, but does not prove the
ordinary UI generates out-of-domain commands.
