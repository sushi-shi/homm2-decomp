# G01: retain the button's common-dispatch goto

The complete `goto normalEvent` versus `break` experiment rejects the
structured replacement: the candidate shrinks from1240 to1234 bytes and
from83 to81 blocks, omitting the retail tail stub. The goto is meaningful
retail control-flow structure, not removable decompiler punctuation.

The retained function is independently checked against genuine retail:
1240 equal instruction bytes with complete DIR32 sites and all22 ordered
target operands. Its tail uses these exact short jumps:

```
004d3d4e eb 0e  jmp 004d3d5e  ; goto's forward stub reference
004d3d50 ...                  ; widget::Main dispatch
004d3d5c eb 02  jmp 004d3d60  ; return skips the stub
004d3d5e eb f0  jmp 004d3d50  ; stub returns to common dispatch
004d3d60 5f     pop edi       ; epilogue
```

The loop, tagged message payload order and base dispatch are unchanged.
Reproduce the retained proof with `PYTHONPATH=scripts python3
docs/reconstruction/check-function.py BASE/BUTTON 0xd3890`. The measured
source alternatives are in `docs/matching/button-Main/structured-tail.cpp`;
logs and full results are `build/g01-{matrix,retail-proof}.log` and
`build/g01-batch/results.json`. No code change is retained for this finding.
