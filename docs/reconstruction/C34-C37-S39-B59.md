# C34/C37/S39/B59: spell widgets

Starting at clean `0bd4eda06`, both complete bodies and their real message,
window and game-member types were reread: ViewSpells (`0x546ee`) and
UpdateSpellWidgets (`0x548cf`). The four call sites pass readOnly0 or1;
the destination remains i8, so direct assignment also retains the same
narrowing for other inputs. Both literal APIs already accept H2_CONST text.
No owner header or shared API is changed.

## Applied source recovery

Eight written casts disappear across the two functions:

- ViewSpells passes both literals directly and assigns readOnly directly.
  Its tab selector now chooses the two named tab IDs. It retains the outer
  i16 cast: the message ID field is i32 and retail sign-extends the selected
  value through16 bits before storing it.
- UpdateSpellWidgets selects WIDGET_COMMAND_CLEAR_FLAGS or
  WIDGET_COMMAND_SET_FLAGS directly at both mana-digit sites. This removes
  two bool-to-int and two computed-enum casts while preserving the exact
  named command domain and comparison thresholds.

This is more than deletion of syntactically redundant casts. VC6 emits
an extra byte-normalization AND for the bare arithmetic bool operand,
but lowers adjacent named enum selections to the original setcc/add code.
The corresponding catalog entries now describe that cast-free alternative
and avoid claiming original source tokens from a narrowing instruction.

## Text bounds and remaining contracts

`check-spell-widget-text.py` checks all65 source spell names against every
ordered pointer and string in the hash-verified retail table at0x4fec04.
The longest CP1251 name is20 bytes (Истинное воскрешение).
Both complete name/cost formats, "%s\\n[%d]" and "%s [%d]", need at most
35 bytes including NUL even for an arbitrary signed i32 cost:20 name,
one separator, two brackets, eleven decimal characters and one terminator.
Each signed mana remainder has magnitude at most9 and needs at most3 bytes
including NUL. All fit the actual768-byte gText owner.

This proves these formatter capacities with the retail catalog, not arbitrary
replacement text or invalid spell IDs. It does not prove live window/hero/
callback lifetimes, resource widget availability, correct category/count/page
state, or a valid GetNthSpell result. The fixed loop visits12 widgets, but
its spell-index validity still depends on those contracts. The window
resource name spellwin.bin needs13 bytes including NUL and fits the real
20-byte heroWindow name owner. No gameplay, invalid-input or lifecycle
hardening is introduced.
