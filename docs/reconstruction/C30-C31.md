# C30/C31: actual length and palette-index roles

Applied: `game::ShowMoraleInfo` and `game::ShowLuckInfo` keep `strlen` results
in a `u32 modifierStart` and compare them directly, removing two `i32` casts.
This is the VC6 CRT's unsigned 32-bit size domain, not a signed game statistic.
Both functions' buffers and output bounds are separately checked in [B52](B52.md).

Each function's complete four-arm matrix independently crossed signed/unsigned
local type with cast/direct comparison. All four arms are byte-identical:

| Target | Completed | Time | Bytes / relocs | Matching blocks |
| --- | --- | --- | --- | --- |
| ShowMoraleInfo `0x0046b118` | 4/4 | 6.97 s | 1427 / 119 | 74/74 |
| ShowLuckInfo `0x0046b6ab` | 4/4 | 6.93 s | 830 / 78 | 41/41 |

Artifacts: `build/c30-{morale,luck}-{axes,manifest}.json` and the corresponding
`-batch/results.json`. Both matrices completed without truncation, restored
source, and every arm passed the matrix's target-local strict check. No AST
mutations or TU-state probes were needed for these byte-neutral type changes.

Retail and every candidate retain the same calls and unsigned-sized comparison:

| Target / offset | Retail and current VC6 |
| --- | --- |
| Morale `+0x54b` | `e8 …` — call the same `strlen` |
| Morale `+0x553` | `39 45 f8` — compare saved length at `[ebp-8]` with EAX |
| Luck `+0x2fb` | `e8 …` — call the same `strlen` |
| Luck `+0x303` | `39 45 fc` — compare saved length at `[ebp-4]` with EAX |

`SmackFade` also now assigns `g[f] = a` without its C-style `u8` cast.
This is not an unchecked large integer: each source/destination color average
is in `0..255`; their absolute difference is at most 255, below the initial
distance sentinel 999. The first inner iteration therefore assigns a candidate,
and every candidate color is `10..35`. The initial `a = -1` cannot reach this
assignment when the required palettes are valid. The loop index remains an
ordinary signed arithmetic local, and the destination is a real byte lookup table.

The complete C-style/static-cast/implicit-assignment matrix compiled 3/3 arms in
5.75 s; all have 566 bytes, 13 relocations, 19/19 matching blocks and pass the
target-local strict check. Artifacts: `build/c31-{axes,manifest}.json` and
`build/c31-batch/results.json`. At function `+0x17c`, `8a 55 fc` loads the
index byte; at `+0x17f`, `88 11` stores it to the mapping entry, identically in
retail and all three source arms. Allocation, pixel-owner and palette-extent
contracts remain B51; no fake buffer or extra initialization was introduced.

All three retained edits together pass the native comparison for **every one of
KB's 78 emitted functions and every allocated section**, with complete ordered
relocations/addends (`build/kb-scalar-native.log`). Independent genuine-retail
checks also pass all bytes, DIR32 sites and ordered targets for all three
functions (`build/kb-scalar-0x<RVA>-retail.log`). The full build passes.
