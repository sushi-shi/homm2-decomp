# O01: recover the Miles sample-state owner

`StartupMilesSamples` cleared 0x48 bytes through `&gMilesSamplesReady`, whose
declared object was only four bytes. The code accessed three separate globals
as one allocation. Recover `MilesSampleState` in the owning audio header:

| Member | Offset | Size | Retail VA |
| --- | --- | --- | --- |
| ready | 0x00 | 4 | 0x005396d8 |
| handles[16] | 0x04 | 64 | 0x005396dc |
| handleCount | 0x44 | 4 | 0x0053971c |

The owner is exactly 0x48 bytes, with every field used. The separate
`gMilesSampleVolumes[32]` occupies 0x40 bytes at `0x00539720`. Verified retail
agrees with the original source addresses. Earlier corrections were based on
the wrong control and have been reverted; see [D01](D01.md).

The clear becomes `memset(&gMilesSamples, 0, sizeof(gMilesSamples))`, and all
state consumers use real fields. No cast, raw offset, alias, fake padding or
out-of-object pointer is needed. Source line count and declaration order of
the effective storage remain unchanged.
