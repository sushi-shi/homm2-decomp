# O03: use the palette's real level dimension

Applied in DimBitmapArea:

```cpp
// Before: indexing beyond the innermost 256-byte array for level > 0.
uDimPal[0][0][level * DIM_PALETTE_LEVEL_STRIDE + *gDimPtr]
// After:
uDimPal[0][level][*gDimPtr]
```

The declared owner is `u8 uDimPal[3][4][256]`. Both direct callers were
checked: widget dimming passes zero; combat victory dimming passes three.
The byte pixel value is necessarily 0..255. The obsolete private stride enum
was removed; neither allocation nor serialized layout changes.

## Native proof

VC6 SP5 `ninja base` passes. All seven emitted functions (four game helpers
and three compiler helpers), their raw instruction bytes, ordered relocation
sites/types/targets/addends and every allocated section are identical. The
DimBitmapArea function remains 205 bytes.

## Monochrome icon decoder follow-through

The same cross-subarray expression appeared twice each in `DimIconToBitmap`
and `FlipDimIconToBitmap`. All four now use `uDimPal[0][color][*s_dst]`.
The private 0x100 stride enums are removed. Caller review establishes levels:
`icon::DimToBuffer` passes zero in either orientation; the combat mouse passes
two; grid shading passes shade minus one after excluding zero, with all shade
stores limited to 0, 1, or 3. No unproven full-palette flattening is introduced.

Both TUs pass `compare-objects.py`: four emitted functions per TU, no byte,
ordered relocation, or allocated-section differences. The game bodies remain
855 and 963 bytes. `check-dim-icons.py` additionally verifies both game bodies
and their four annotated compiler helpers against the hash-checked retail
image: equal bytes, full DIR32 site lists and all ordered destinations/addends.
Private names are resolved within the owning TU, not through a global name map.

Before objects: `build/reconstruction-Icond2b-before.obj` and
`build/reconstruction-Icondf2b-before.obj`. Current objects are under
`build/objdiff/base/BASE/`; full reports are `build/proof-Icond2b.log`,
`build/proof-Icondf2b.log`, and `build/dim-icons-retail-proof.log`.
`homm2 build` passes. Pre-clipping row-pointer formation, frame/stream extents,
and the flipped full-run clipping predicate remain separate B28 findings.
