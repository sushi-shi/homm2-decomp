# S14: three scales, not four-byte C++ arrays

`advManager::VWCompleteDraw` declared three four-element byte arrays but
initialized and indexed only three entries. `VWInit` assigns lookup indices
0, 1 or 2; the scale values are 4, 6 and 12. Only the dialog cycle changes
the scale, using those same three values. No address of any offset array
escapes and no sizeof operation observes its former fourth byte.

Use `ADVMGR_VIEW_WORLD_SCALE_COUNT` (3) for `iconX1`, `townFlagX0` and
`letterY1`, deleting the private four-element capacity. Compiler alignment
still reserves four stack bytes per array; that does not require inventing
a fourth C++ element.
