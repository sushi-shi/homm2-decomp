# C43/S41/S42/B65: new-turn text and remaining unread locals

The parent is `e490bc850`. Four complete game bodies were reread along
with their owner declarations and retail dossiers. Five casts are removed:
four text pointer casts in DoNewTurn and one hero-ID assignment cast in
CheckHeroConsistency. Four unused-storage candidates remain after measurement.

## Text ownership and CP1251

DoNewTurn's lowerName19 is now a char[52] text buffer. ToLowerCp1251 takes
an unsigned byte and returns a text character, mirroring the existing
ToUpperCp1251 helper. It folds ASCII capitals and basic Russian capitals,
including Ё; all other byte values remain unchanged. Signed text input
converts to the unsigned parameter before comparison, so Cyrillic bytes
do not become negative comparison operands. The fold preserves length.

Five structural owner versions were tested: the original byte buffer,
a char buffer with unsigned casts on individual reads, a char buffer with
a separate unsigned first-letter local, and char-buffer helpers returning
either char or u8. These cross retention/deletion of the write-only music
buffer and retention/removal of the player-argument cast: 20 complete arms.
The selected char-returning helper with music and player cast retained is
trial 12, reproducing all 1277 bytes and ordered targets. The explicit-read
and u8-returning helper versions also preserve the baseline sequence.
The extra-local version is 1286 bytes, with a distinct frame sequence.

The music filename buffer receives two literal copies but is never read.
Deleting the buffer and both copies changes the selected family to 1239
bytes. Removing the player-ID argument cast changes it to 1275 bytes.
Neither is retained. These are measured constraints of this parent, not
claims that every possible later structural recovery has been ruled out.

The actual recovered helper is extracted into a host test and checked for
all 256 byte values through both signed-text and unsigned-byte input paths,
under C++98 and C++20. The expected table is independently constructed
from the ASCII and basic Russian alphabets. This supplements, rather than
replaces, the full VC6 native proof and both complete GAME dialect parses.

## Complete bounds

`check-newturn-text.py` reads all 66 retail plural creature names, 10 month
names, 15 week names and all 7 format strings. The longest plural name needs
22 bytes including NUL, within 52. One-byte lowercase conversion cannot
increase it. The music literals need at most 12 bytes in 16.

The seven complete gText results require at most 137, 142, 75, 162, 73, 70 and 152
bytes including NUL, all within 768. These bounds include both substituted
creature names and the nonnegative signed-byte day count. Player names
must terminate within their 21-byte rows. Valid period/creature/player and
terrain indices, current owners and dialog lifetimes remain B65 contracts.
No new input guard or string truncation is added.

CheckHeroConsistency still requires valid player counts, hero lists and
occupied-town IDs; its map hero metadata is explicitly checked 0..53.
Its five-slot army scans cover 54 heroes and 72 towns. R09 index reuse remains
separate. RandomizeTown's initial map/extra access and successful town lookup
remain caller requirements despite later ConvertObject clipping.
