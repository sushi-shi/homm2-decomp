# U08: two actual bottom-view widget arrays

Applied: replace two anonymous unions with two `widget*[12]` owners. Their
integer locator aliases were used only to clear pointer storage in `Open`.
All remaining consumers use the common widget interface for insertion,
removal, null checks and deletion. No consumer needs the overlaid derived
pointer type. No cast, helper accessor, union, padding alias or pointer
arithmetic across a scalar remains in this storage.

| Former view | Actual owner/index | Manager offset |
| --- | --- | --- |
| background | primary[0] | 0x3a |
| foreground/hourglass | primary[1] | 0x3e |
| icons[i] | primary[i+2] | 0x42+4i |
| allTexts[i] | secondary[i] | 0x6a+4i |
| hero texts[i] | secondary[i+1] | 0x6e+4i |
| locator integer arrays | removed; initialize pointer arrays with NULL | unchanged |
| icon/text padding and reserved word views | removed; storage is covered by the arrays | unchanged |

Both arrays retain twelve entries: `ClearBottomView` actually visits and
clears all twelve, while individual modes occupy different subsets. The
class remains packed and 0x37e bytes. All source consumers were read in full:
Open, ClearBottomView and the five enemy/new-turn/resource/kingdom/hero
bottom-view builders. Their source line counts are unchanged.

## Evidence

The before snapshot is `build/u08-before`, taken after B44 and before U08.
`build/u08-proof.py` applies the established `compare-objects.py` census to
all before/after objects: **98 TUs, 1,826 emitted functions, zero differences**
in bytes, ordered relocation sites/types/identities/addends or any allocated
section (`build/u08-whole-native.log`). This includes exception-handler code
and data; only the established compiler-private normalization is used.

The supplemental scoped retail check in `build/u08-retail.log` confirms
every instruction byte for all seven functions. ClearBottomView also passes
every ordered target and the complete DIR32 list. The other six contain
existing `$L...` exception-handler references and `__except_list` pseudo
relocations that this narrow checker cannot resolve/filter. Therefore this
is **not** a claim of independent full retail closure for those six bodies.
The complete native before/after comparison covers their unchanged exception
machinery and every relocation; every ordinary target in the scoped retail
report resolves correctly. Sizes remain 2389,294,1339,903,900,891,1519 bytes
for Open, Clear, Enemy, NewTurn, ResMsg, Kingdom and Hero respectively.

`homm2 build` passes and all877 selftests pass without skips
(`build/build-u08.log`, `build/selftest-u08.log`). The
[owner/index codegen evidence](../patterns/widget-pointer-array-owner.md)
shows representative actual bytes.

This is evidence-backed shared-owner reconstruction, not a compiler-state
probe. It preserves the existing new-turn overwrite of secondary slot zero
and all existing text capacities/formatting. Those separate lifecycle/bounds
concerns are not fixed by making the storage owner accurate.
