# C74 / S67 / B89 — Windows entry, messages and menus

All sixteen functions, all 587 source lines (including the private constant and
21 data owners), and the complete 86-line owner header were read. Each function
has all ten verdicts in `reviews.json`; this report distinguishes actual bounded
storage from input/API contracts that the retail program does not enforce.

## Applied and retained source

C74 removes two written conversions: `reinterpret_cast<HMENU>(hmnuDflt)` in
`AppInit`, since the declaration already has precisely that handle type, and
`static_cast<u32>(-1)` in `SetMenus`, since comparison with the unsigned menu ID
already performs the conversion. Both complete two-arm products reproduce the
same function bytes and relocations, individually and together.

The remaining casts express real boundaries: the instance address logged as a
32-bit integer; the SDK encoded background brush; icon handle in `LPARAM`;
window handle compared with `WPARAM`; the preserved about-dialog command-window
slot; the command enum; and the about callback conversion to `DLGPROC`. In this
actual `/DNO_STRICT` SDK, `DLGPROC` is `FARPROC`, not the strictly typed four-argument
callback. Removing that cast based on a different SDK branch is not justified.

S67 tests all subsets of each pair of unused locals/stores. The original
`AppAbout` is 103 bytes; alternatives are 88, 98 and 82. `UpdateDfltMenu` is 177
bytes; either single deletion stays 177 but changes text, and both produce 175.
`SetMenuStatus` is 279; either store/slot deletion produces 276 and both 273.
The style API calls remain in every tested alternative. All originals are
retained. Five complete products cover 16 arms in 9.932663 seconds; there is no
truncated product or claim of a cross-family/compiler-state census. Full source
arms, hashes and topology are in `docs/matching/kbwin/`.

There are no gotos, manual argument-slot readers, enclosing-owner subtraction,
invented unions or fabricated stack aggregates. `MSG`, `WNDCLASSA` and `RECT`
are real SDK owners. The shared `lTemp` genuinely exists at VA `0x005268b8`,
and its timer/style stores are reproduced by retail. Its unrelated global
scratch roles remain explicit debt; inventing separate globals or deleting
those stores is not an established recovery. No role-split experiment is claimed.
