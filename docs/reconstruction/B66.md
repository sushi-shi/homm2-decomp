# Town text bounds

`check-town-text.py` uses the hash-pinned retail executable's CP1251 strings,
pointer tables and prerequisite masks. It also checks each relevant private
format operand against the current compiled object. Bounds include NUL:

| Output | Bound | Declared capacity |
| --- | ---: | ---: |
| All town status-message alternatives | 70 | 80 |
| Town-object filename / castle icon filename | 13 /13 | 16 |
| Largest well-detail fragment | 27 | 40 |
| Full well-detail chain, all optional appends | 99 | 768 |
| Signed16 resource-cost decimal | 7 | 10 |
| Signed32 primary-stat line | 13 | 200 |
| All four primary-stat lines | 49 | 768 |
| Building description with title | 187 | 400 |
| Full purchase description and prerequisites | 172 | 400 |

The status maximum is the two-creature exchange message. Every other action,
fixed command, faction name, selected creature and dwelling recruitment string
is included. The date bound uses three full unsigned16 values and is41 bytes;
it does not depend on the usual day/week ranges.

Building enumeration covers171 valid faction/building combinations. Fifteen
unsupported dwelling entries contain creature -1 and are explicitly excluded,
not treated as valid string-array indices. GetBuildingInfo's own intermediate
buffer is400 bytes; every description and name is percent-free. The model
includes the well's substituted creature name, the special necromancer shrine,
all prerequisite names from the actual bitmask and the conditional mage-guild
prerequisite. It also accounts for the final newline/space append. This closes
the selected B52 capacity/format-directive question for valid building domains.

Independent whole-function byte/DIR32/ordered-target checks pass GetBuildingInfo
(377 bytes) and GetBuildingName (105 bytes), in
`build/b66-building-{info,name}-retail.log`. The bound report is
`build/b66-town-text.log`.

This is not a complete input-validation proof. Runtime town names are returned
from a13-byte field but are passed directly as a format in SetupTown; both
termination and absence of format directives need producer contracts. Corrupt
creature/faction/speed IDs, unsupported buildings, window/resource lifetimes,
allocation failures and render dimensions are separate B67 obligations. The
well bound allows the full signed8 statistics/growth range and unsigned16 hit
points, but it still requires a valid speed-text index. No buffers were enlarged
to hide an out-of-domain access.
